# HRS 发行说明

## v2.2.0 · 离线HTML主题切换

- 导出的HTML左侧新增“配色”，离线也能切换现有六套主题，正文底色随主题显示。
- 默认采用导出时的配色，浏览器允许时记住阅读选择；源文和可恢复的工程内容不变。
- 打印和PDF继续使用白色纸面，关闭脚本后仍可直接阅读。
- 整篇和专题分册都支持，无需附带其他文件或联网加载主题。

## v2.0.12

- 修复Word已经导入成功，却因为临时文件无法删除而提示失败的问题。
- 工作文件使用系统临时目录和短名称；真正访问失败会显示读取、写入或保存阶段。
- Word读取和工程保存使用同一个转换Python，原稿与原Word继续保留。

## v2.0.11

- Word导入先得到可编辑稿：列表、脚注、内容控件及域文字不再挡住整篇文稿。
- 嵌套表和单元格图片保留为相邻对象，无法完整转换的局部可对照随工程保存的源Word核对。
- Word读取与保存前复核使用同一转换环境；普通导入和精确来源回编分开处理。

## v2.0.10 · 直接编辑 Markdown

- 无附件Markdown可直接打开并Ctrl+S保存回原文件；HTML/PDF导出到同目录，设置/草稿/备份由应用保管。
- 网页Enter新增的行按原CRLF/LF/CR保存，保留BOM及原有末尾换行；编辑器、光标、专题与实际保存正文一致。
- 导出HTML保留引用块的连续换行；需要附件或Word时显式另存工程，原文件保留。
- 正式发行承接已验收的2.0.8 R2；各安装形式统一版本2.0.10。

## v2.0.8 R2 · Markdown 换行保存修复

直接编辑CRLF文稿时，在网页按Enter新增的行也会按CRLF保存，原有BOM与末尾换行保留；LF稿保持LF，原本没有末尾换行的稿不强加。保存后的编辑器、光标、专题和导出源稿与实际文件一致，重复保存不会重复添加换行。

## v2.0.8 · 直接编辑 Markdown

- 无附件的Markdown可以直接打开并Ctrl+S保存回原文件，HTML/PDF导出到旁边，不用建立工程文件夹。
- 设置、恢复草稿和保存备份由应用保管；外部修改会阻止覆盖。需要图片或Word时可明确另存新工程，原文件保留。
- 修复导出HTML把引用块连续两行合成一行的问题；真正分段仍有段间距。

## v2.0.7 · Word超链接导入

Word导入新增与导出一致的beta标记。普通网页/邮件链接和能可靠定位的文内章节、图表链接可保留；表格、题注中的链接也按同一方式处理。导入后可以在预览、离线HTML和再次导出的Word中使用。

无法定位或不安全的目标不再因为“缺少保留目标映射”拒绝整篇：显示文字保留，原地址列在待确认项和新工程诊断中。相对路径不猜基准，复杂域/嵌套结构仍有明确限制。更新时使用本版配套Word组件。

## v2.0.6

- 可以直接从“打开→导入Word”选择DOCX，转换为可继续编辑的HRS工程。正文、可识别标题、表格、图片/组图及受支持公式沿原桥接处理，原Word保留。
- 导入后先查看状态和待确认项，再选择新工程目录；当前未保存稿仍有原来的保存/取消提示。原生公式工具与Word导出共用设置，不需要Node或另开浏览器。
- 纯文字工程的空素材目录也能正确保存；登记失败时保留完整新目录。继续包含表格/题注跨公式加粗修复。

## v2.0.5

- 表内或题注中写`**参数 $x$ 的说明**`时，加粗可以完整跨越公式，预览、阅读及导出HTML保持一致；普通与增强表共用。
- 行内代码示例和原Markdown保持不变，数学字形仍使用TeX命令控制。手册明确整篇Word导入和快捷粘贴的当前范围。

## v2.0.4

- 基本流程图重新支持直接拖动节点，连线与箭头跟随；位置随保存、重开和HTML/PDF/Word导出保留。
- 改字、加减节点/连线继续使用原窗口；增加“自动布局”清除手动位置。取消不改原稿，应用可撤销。
- 保留当前Pele核心和Mermaid源语法，复杂图仍直接改源码。恢复的是原基本流程图的拖动范围，不将复杂图强转为简图。

## v2.0.3

- 流程图继续使用Mermaid语法，内部改用更轻量的完整Pele渲染器；中文、多行节点、图题及编号沿用原稿。
- 切换主题颜色时复用图表布局；图内公式使用原MathJax，导出HTML/PDF/Word保留颜色及字形。
- 预览、图形编辑和阅读包使用同一核心；复杂图仍可直接编辑源码。布局与旧引擎略有不同，兼容差异见手册，原稿不会自动改写。

## v2.0.2

- 编辑标题文字时，自动章节号始终保留；快速改字再撤销也会及时恢复预览。
- 已有普通Mermaid流程图可以直接补图题，无需手工改成对象源码。
- 聚焦自由专题时使用独立目录和章节/图表/公式编号，切回全部恢复全文编号；原图表引用仍可跨专题定位。
- Windows中的文件、文件夹路径链接可单击交给系统打开，编辑器保留当前文稿。

## v2.0.1

- 在查找框等输入框中撤销时，不再误撤销文稿；源码和表格窗口保留各自的撤销体验。
- 已有项目支持./assets和安全图片子目录，预览、保存和HTML恢复保持一致；独立Markdown图片保存后照常成为编号对象。
- 反复开关表格编辑窗口后，旧控件及键盘监听可正常释放。
- 说明HRS与DocFlow各自携带的Bridge版本，以及匹配组件的核对方式。

## v2.0.0

- 统一文档编号：工程章节/图表固定编号，自由笔记可选；新增两模式均可选的公式编号。Markdown/增强表、普通/对象Mermaid和全部块公式共用序列，行内数学不编号。
- 移除按插入类型区分的编号/不编号公式、流程图入口。ID与显示数字分离；旧源码仍读取，不批量重写。普通Markdown表的工程表号将因此变化。
- Word/WPS混合粘贴增加受支持公式的LaTeX转换；可明确对应的独立外部括号式号去除，表达式内部数字不动。KSEE3/MTEF3与OMML/MathML的支持边界及可选转换器见手册。
- Word公式支持原生SEQ/REF；关闭编号仍保留“该公式”定位。新页面模型绑定document-v2编号策略和render_options，配套Bridge0.3.0，旧Word组件需一同更新。
- 显式引用匿名表格/块公式/流程图时，沿原事务补稳定身份并插入引用，可一次撤销；普通编辑与只读导出不主动改源。
