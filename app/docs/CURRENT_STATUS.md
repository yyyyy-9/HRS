# 当前状态

自由笔记HTML阅读器消费原专题索引的导出元数据，支持专题范围、目录层级及专题序列，跨专题链接展开目标范围，完整归档不受阅读筛选影响。预览增量更新先移除失效间隔再放置保留节点；连续空行变化不丢后续正文。文稿撤销/重做定位变化范围、双侧提示和前后片段；源码与预览分别控制滚动，单栏不强切视图。软换行、空白行分段、强制换行和Setext标题继续沿原Markdown解析。
标题和图表可显示独立的双排时间信息。元数据消费原IR及章节范围，不在Markdown插入日期或身份注释；章节修改聚合子章节，图表按自身内容更新。旧来源未知日期保持未知，显示设置不参与修改判定。工程、直接Markdown、草稿、受控提交与归档恢复沿同一时间元数据接口；Word仍只消费技术内容。

Ctrl+F/Ctrl+H共用内置面板：源码可按当前专题或全文字面替换，全部替换为一次撤销，渲染和阅读仅查找。显示方式及编号开关在左栏两列维护。管道表格分列保护完整数学区间，并由同一范围选择器服务词法识别、源码折叠和表格编辑；不改写原始TeX。

基础文件写入、摘要及JSON保存已统一到无服务依赖的模块，图片校验/SVG处理独立持有；原授权、锁、备份和快照保护继续由调用方执行。Python传输类型生成浏览器声明，请求边界提供开发期静态检查；对象片段及Word模型只检查传输字段，原语义/资源校验保持。组件源码、模板与浏览器生成副本沿一份来源声明核对文件集合和字节，升级范围进入原发行清单。运行方式、旧浏览器目标和用户文稿格式保持。

产品版本和包修订统一读取release.json。HRS提供浏览器形式和标准Python安装，共用同一app核心。Word组件和模板工具的对应源码分别见components与template-tool。

Word 原生公式从同一页面模型取得，按原始 TeX 与行内／行间类型去重复用并分批转换；每式独立核对映射，原稿及回编记录不变。未使用定义中的公式不因预热失败变成新的输出阻断，实际写入的公式仍须原生转换成功。Word 请求等待预算由服务端下发，覆盖其子进程转换时限，不改变其他接口的默认等待。

打开文稿先准备其异步依赖，成功后一起切换源码与保存身份；失败保留原文稿。正文成功提交后，显示设置更新或旧草稿清理未完成以warnings返回当前revision，界面分别提示，不将其视为正文写入失败。直接Markdown仍按原BOM与换行模式返回已保存缓冲。

公式弹窗提供离线 MathLive 可视输入与 LaTeX 双向同步，分式、上下标、矩阵和对齐等结构可直接编辑；宏定义及不支持的写法保留源码输入。源稿、编号和输出仍由原模型持有，未编辑应用/取消不改写原文。块公式源码范围可见，插入即选择，复制沿统一身份映射。预览及 HTML 旧 tag 不产生重复号，Word 继续遵守工程快照的公式编号开关。

公式结构有数学样例和中文名称，分段函数/等号对齐使用两行模板；窄/宽空格写入实际TeX，多行结构可新增行，普通行间公式可显式保留原式转为多行。不把普通空格或源码Enter误当数学换行，不静默改变行内公式类型。标题栏撤销/重做统一覆盖源码、可视输入和结构操作，只持有本次窗口最近100步；原稿与窗口历史分离，应用仍是一笔文稿事务。源码正文/标题字号和预览/阅读100%至200%显示比例为本机偏好，受保护源块/折叠卡片字号及文稿/导出排版独立；自动折行在目录栏，折叠/展开为随当前范围实际状态变化的单按钮。视图控件的可用状态由共享操作管理器保存，载入完成后恢复当前状态。左栏直接从最近打开开始，不重复显示静态本机运行卡片。

目录提供层级树、快速折叠及同级整节拖动，同级条目有无下级标题占用相同的箭头栏。Markdown 片段支持显式字段/日期/光标和按节追加，保存在应用数据区，不运行代码。引用沿现有链接定位，不提供源码悬浮窗或使用位置窗口。Agent 可按唯一标题路径对章节正文 append/prepend/replace-body，继续使用原 plan/apply 全文摘要、锁、备份、原子提交，范围外字节保持。

编辑器中的阅读视图只读，图表、公式和题注不打开编辑窗口，任务框与目录移动、文稿撤销/重做不可用；导航、链接、放大和复制保留。可视公式等待字体加载后接受命中操作，字形及选区更清晰；孤立上下标的拖选替换保留其层级，其他结构沿原数学模型。短块公式不再使用固定最小高度，预览与离线HTML共享段距；普通长英文的单词换行保持浏览器行为。

## 编辑与文稿

同一文稿连续预览时，本地图片和公式SVG按内容及显示上下文复用；安全的未变公式段落可整块保留，提交时更新源码范围和公式绑定。带链接、脚注或复杂交互的块沿原新外层/显示叶节点路径处理。数学缓存优先保留当前工作集，并同时限制条数和序列化尺寸；宏定义不按普通公式缓存。长数学排版分批让出执行时间，源稿、模式或会话变化时放弃过期结果。仍复用原完整解析，不承诺任意长稿完全局部解析或消除所有浏览器重绘。

Markdown单栏更新同一源模型、目录、注释、草稿及保存，隐藏预览延后到切回分屏/阅读时补齐。HTML/PDF/Word输出继续独立处理最新完整源稿，不使用未更新的隐藏预览。切换文稿清除数学和图形缓存，Chrome112/Edge92兼容目标保持。

分屏/阅读选区可显式复制Markdown；普通文字保留源位置，复杂结构或格式端点复制完整源码块，附件复用原对象剪贴板。缩进代码显示原因并提供只作用于当前顶层块、可撤销的“转为正文”；标准Markdown语法及列表/脚注续行保持。

支持自由笔记、工程报告、Markdown源编辑、分屏预览及阅读。自由笔记按H1聚焦时，目录只列本专题，章节/图表/公式按专题派生编号，返回全部恢复全文；显示开关、全文ID和引用定位分开管理。工程章节号在标题文字编辑范围之外；普通Mermaid可在原编辑窗口填写图题。图表对象、脚注、引用、公式、查找、恢复草稿和附件管理使用同一源模型。Windows文件/文件夹链接显式点击后交系统打开，未保存稿不猜相对路径基准。

工程report.md和assets是内容真源；无附件Markdown可从“直接编辑Markdown”原位保存，以原文件为唯一正文。HTML/PDF输出同目录，设置/草稿/备份在应用数据区；新增行在保存时统一到原换行模式，BOM及非空稿件原有末尾换行保留，实际正文同步缓冲/savedMd及UTF-16选区。原本无末尾换行的稿件不强加；外部修改冲突保护复用原提交链。添加附件或Word操作先显式另存新工程，原文件保留。预览与离线HTML的连续引用行均保留换行。保存导入的独立本地图片时创建正常图片对象。临时工程稿可独立检查和编译，回写须先查看差异并显式提交；来源或附件变化时拒绝覆盖。

Mermaid源文由完整本地Pele1.10.0渲染，预览、编辑和阅读包共用；布局缓存与主题颜色分离，图内公式沿原MathJax排版，HTML保留主题变量及独立字形，PDF/Word图形固定最终配色。对象、编号、回编原文、A0及Bridge页面模型保持。兼容目标为Mermaid12.1；主题指令、HTML标签、脚本回调和布局差异见手册。基本流程图支持拖动及旧%% pos位置，连线同步、应用/取消、撤销、保存重开与输出保持；自动布局可清除手动位置。

源码区支持Word/WPS混合粘贴：字面正文、图片对象、普通／合并表格和受支持公式按原顺序一次插入，草稿附件及撤销复用原机制。Windows显式剪贴板读取补足浏览器未暴露的图片；不下载外图，嵌套表／表内图片等明确拒绝整段。具体限制见使用手册。

普通/增强表格与图表题注在同一次Markdown内联解析中保留跨公式的强调，`**参数 $x$ 的说明**`在预览、阅读和HTML中一致；代码字面不变，数学字形继续遵守TeX。此项未改变Word页面协议和组件。

## HTML与Word

Word导入使用系统临时目录，文件读取和工程保存由同一转换环境完成。

Word已成功导入并保存时，临时文件清理失败不会影响导入结果。真正的读取、写入或保存失败会显示具体操作阶段和文件路径，原件及当前稿保留。

普通Word导入使用可编辑模式：正文、样式/直接自动列表、内容控件、脚注、可识别图表和公式进入同一HRS源格式。普通域保留保存的显示结果；嵌套表及单元格图片移为相邻对象，原位置保留引用；浮动图转正文图，受支持位图的裁切/旋转固化为预览。局部不能转换项在原位置提示待确认，源Word保存在output/word-import-source.docx，不因局部差异拒绝整篇。普通外来稿默认自由模式；工程输出仍按工程规则检查。

自身导出件的可用同名.docx.hrs-bridge.json仍用于精确恢复；自动映射缺失、损坏或不适用于当前内容时，普通导入按当前Word建立新身份并说明差异，不恢复旧文字覆盖当前编辑。CLI显式from-docx --mode roundtrip及显式来源映射继续核对原身份；--mode editable与HRS菜单使用兼容导入。不能读取的文件/损坏包、资源上限、来源变化、取消和目标已存在仍明确失败；原件和当前稿不改写。 读取、冻结和提交前复核均由同一转换Python执行，前端复用当前页面序列化；诊断在核对窗口和工程JSON中可见。原生超链接及可确认书签沿现有映射，未知/危险目标仅保留文字和目标记录。

HTML支持阅读和可回编归档，资源随文件携带。整篇和专题分册内置六套主题，可在离线阅读器中切换；默认采用导出配色，本地阅读选择独立于归档源稿。正文纸面随主题，打印/PDF白底；无脚本或本地存储时正文仍可读，帮助页保持默认蓝色。可回编归档保留Markdown和所需附件；普通任意HTML不属于可回编输入。

Word输出复用Bridge/WPS原生转换、样式、编号、公式、脚注和引用。模板工具可将报告样式设置到带封面/目录/页眉的模板中，通过正文书签装配内容。附带通用模板由项目生成，格式母模板版本0.3.11，工具版本1.0.3。

Word组件中的原生依赖适配Windows x64 CPython3.13；浏览器便携包已包含匹配环境。其他Python环境须提供匹配依赖，原生公式按需选择Pandoc。

## 程序接口

A0和/api/validate提供源码契约检查，明确preflight.complete=false；完整输出检查使用hrs check或页面预检。源码契约检查不能代替Word编译或领域内容判断。

plan只产生候选和差异，apply必须显式携带审查摘要，重新核对源稿、范围和资源，复用锁、备份及原子保存。程序不内置模型API客户端，不执行文稿中的代码。

CLI新输出使用独占创建，写入失败清理自身文件；计划和候选成组清理，无法清理则返回残留路径，旧文件不覆盖。HTML恢复以新工程目录交付为完成点，后续临时清理失败随成功回执提示。成功/失败传输类型分开，保留任务状态的可空error字段。源码与便携发行必须提供对应的组件来源声明。

## 支持范围

Windows浏览器便携包使用本地Chromium系浏览器。桌面宿主源码与浏览器共用核心；窗口、剪贴板、打印和办公软件页面按相应集成测试验证。

任意Word/HTML无损双向转换、跨来源混合合稿和复杂编辑后回编仍按[长期路线](LONG_TERM_ROADMAP.md)逐项扩展。浏览器兼容目标保持Chrome112/Edge92；系统剪贴板、办公软件和实际旧系统环境的边界分别验收，不能以DOM复用保证所有硬件上不闪烁。

标准wheel/sdist以hrstudio为安装分发名，命令仍为hrs，模块为html_report_studio；Python/Conda元数据与公开tag使用同一版本。v1 Conda配方从相同元数据生成，本地与提交版仅来源位置不同。PyPI尚未上传，conda-forge公开安装须等配方审核及频道构建完成；PR本身不等于已发布。自有代码使用GPL-3.0-or-later，依赖和文稿权利见随包LICENSING.md。
