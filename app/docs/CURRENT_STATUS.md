# 当前状态

产品版本和包修订统一读取release.json。HRS提供浏览器形式和标准Python安装，共用同一app核心。Word组件和模板工具的对应源码分别见components与template-tool。

## 编辑与文稿

支持自由笔记、工程报告、Markdown源编辑、分屏预览及阅读。自由笔记按H1聚焦时，目录只列本专题，章节/图表/公式按专题派生编号，返回全部恢复全文；显示开关、全文ID和引用定位分开管理。工程章节号在标题文字编辑范围之外；普通Mermaid可在原编辑窗口填写图题。图表对象、脚注、引用、公式、查找、恢复草稿和附件管理使用同一源模型。Windows文件/文件夹链接显式点击后交系统打开，未保存稿不猜相对路径基准。

report.md和assets是内容真源。保存导入的独立本地图片时创建正常图片对象。临时工程稿可独立检查和编译，回写须先查看差异并显式提交；来源或附件变化时拒绝覆盖。

Mermaid源文现由完整本地Pele1.10.0渲染，预览、编辑和阅读包共用；布局缓存与主题颜色分离，图内公式沿原MathJax排版，HTML/PDF/Word图形固化主题和字形。对象、编号、回编原文、A0及Bridge页面模型保持。兼容目标为Mermaid12.1；主题指令、HTML标签、脚本回调和布局差异见手册。基本流程图已恢复拖动及旧%% pos位置，连线同步、应用/取消、撤销、保存重开与输出保持；自动布局可清除手动位置。实际验证见交付说明；旧Chrome112/Edge92、其他系统及办公软件页面不沿用本机自动化结论。

源码区支持Word/WPS混合粘贴：字面正文、图片对象、普通／合并表格和受支持公式按原顺序一次插入，草稿附件及撤销复用原机制。Windows显式剪贴板读取补足浏览器未暴露的图片；不下载外图，嵌套表／表内图片等明确拒绝整段。具体限制见使用手册。原生应用、浏览器与纯契约的本次执行结果分别记录，不互相代替。

普通/增强表格与图表题注在同一次Markdown内联解析中保留跨公式的强调，`**参数 $x$ 的说明**`在预览、阅读和HTML中一致；代码字面不变，数学字形继续遵守TeX。此项未改变Word页面协议和组件。

## HTML与Word

“打开→导入Word”已接入配套Bridge的from-docx扫描/识别与受限回编入口，生成独立HRS工程。当前页面提供既有组图/表格/公式序列化，无需Node或第二个浏览器；新工程保存后按原有提示决定是否切换。COMPLETE与NEEDS_REVIEW分别展示，诊断和来源摘要随工程保留；取消/失败不覆盖当前稿或原DOCX。自身导出件使用同名来源映射，不能表达的对象/域明确拒绝。快捷粘贴与整篇导入按各自支持范围工作；普通位图不猜成数学。

HTML支持阅读和可回编归档，资源随文件携带。可回编归档保留Markdown和所需附件；普通任意HTML不属于可回编输入。

Word输出复用Bridge/WPS原生转换、样式、编号、公式、脚注和引用。模板工具可将报告样式设置到带封面/目录/页眉的模板中，通过正文书签装配内容。附带通用模板由项目生成，格式母模板版本0.3.11，工具版本1.0.3。

Word组件中的原生依赖适配Windows x64 CPython3.13；浏览器便携包已包含匹配环境。其他Python环境须提供匹配依赖，原生公式按需选择Pandoc。

## 程序接口

A0和/api/validate提供源码契约检查，明确preflight.complete=false；完整输出检查使用hrs check或页面预检。源码契约检查不能代替Word编译或领域内容判断。

plan只产生候选和差异，apply必须显式携带审查摘要，重新核对源稿、范围和资源，复用锁、备份及原子保存。程序不内置模型API客户端，不执行文稿中的代码。

## 支持范围

Windows浏览器便携包使用本地Chromium系浏览器。桌面宿主源码与浏览器共用核心；窗口、剪贴板、打印和办公软件页面按相应集成测试验证。

任意Word/HTML无损双向转换、跨来源混合合稿和复杂编辑后回编仍按[长期路线](LONG_TERM_ROADMAP.md)逐项扩展。旧浏览器输入时可能出现图片重绘，优化安排见[短期计划](SHORT_TERM_PLAN.md)。

标准wheel/sdist以hrstudio为安装分发名，命令仍为hrs，模块为html_report_studio；Python/Conda元数据与公开tag使用同一版本。v1 Conda配方从相同元数据生成，本地与提交版仅来源位置不同。PyPI尚未上传，conda-forge公开安装须等配方审核及频道构建完成；PR本身不等于已发布。自有代码使用GPL-3.0-or-later，依赖和文稿权利见随包LICENSING.md。

相关入口：[发行记录](HISTORY_INDEX.md) · [发行说明](CHANGELOG_READABLE.md) · [短期计划](SHORT_TERM_PLAN.md)。

所有Markdown/增强表、普通/对象Mermaid及块公式使用公共编号，源语法不区分是否带号。工程章号/图表号固定，公式由文档选项控制；身份与题名独立。公式粘贴的格式边界见手册，实际本机证据与自动测试分别记录。
