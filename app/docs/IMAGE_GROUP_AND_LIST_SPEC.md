# 组图与列表使用说明

适用版本：**v0.5.6 HF8 PF13.7**。本页说明当前可用行为和源码的对应关系，不是待实施计划。普通操作见[使用手册](USER_GUIDE.md)；语法、字段和校验的唯一依据是[源格式规范](../工程报告源格式_v1_规范.md)。

## 组图布局与编辑

“图片”菜单中的“并排组图”支持自动行数或 1～3 行、1～4 列、2～12 张本地图片。指定行列时不能超过容量；图片按从左到右、从上到下排列，保持宽高比，最后一行允许未填满。复杂不等列数布局不在当前范围。

组图窗口可选多个文件、Ctrl+V 或使用“粘贴一张图”，并可上移/下移、删除、填写子图说明和整组题注。Windows 原生图形粘贴复用既有后端；剪贴板中有 EMF 时保留原件与预览关系。实际可取得的格式取决于来源软件和系统剪贴板，不能保证每次复制都有 EMF。

异步资源处理、草稿与正式保存沿用工程生命周期。取消不修改正式 Markdown；未修改直接应用保留原源文，旧快照拒绝覆盖。素材回收必须显式执行，不通过取消或常规保存自动删除工程原件。

Word下游把每排图片与对应子图说明拆成两行无边框表格，使不同图片高度不再改变题注起始高度；逻辑行列、原图比例及组图身份保持。子图说明允许自然换行，不固定行高裁切；同排图片与说明按可用页面一起排版，多排组图可跨页。

## 整组图号与子图字母

组图使用一个稳定 `fig-` ID，与单图共享图号序列。子图 `(a)(b)…` 是显示标记，按当前顺序派生；默认显示，可在窗口关闭。隐藏字母保留每张图的说明和整组题注，不重排图片，不改变图号或身份。

可选 `rows`、`showSubfigureLabels` 在规范化 IR 中反映布局，Markdown 继续使用既有组图围栏，不保存第二份 JSON 正文。源图与预览关系通过既有图片元数据保留；具体属性见源规范。子图级稳定 ID、单独子图交叉引用与任意不规则网格尚未实现。

## 列表样式与源码

工具栏“列表”提供项目符号、数字、小写字母、括号数字和括号字母五种样式。标准无序/有序 Markdown 保持可读；扩展有序样式由受限 `hrs:list` 注释指定，正文仍使用标准列表语法。增加或删除项目后显示序号由渲染器计算，不把字母或括号数字作为普通段落内容维护。

```markdown
<!-- hrs:list style=paren-decimal -->
1. 第一项
2. 第二项
```

编辑预览和单文件 HTML 读取相同样式；普通 Markdown 阅读器可按标准有序列表显示。IR 的 `list_styles[]` 记录样式及源范围，列表项仍保留在原始 Markdown 中；目前没有完整逐项 AST 或复杂多级编号模板。

## 保存、输出与下游边界

正式工程以 `report.md/assets` 为真源；可回编 HTML 带上源文和必要资源，重新导入后仍按同一契约解析。纯阅读 HTML 不承诺恢复完整工程。

Word/WPS 的自动编号列表、图片表格组图和模板样式由独立下游实现；支持范围与未验证项见[当前状态](CURRENT_STATUS.md)及[Word/WPS 数据接口](WORD_COMPILER_HANDOFF.md)，历史迭代见[更新记录](CHANGELOG_READABLE.md)。HTML显示结果不能替代实际DOCX装配和办公软件验收。
